# Day 3 - Integration, Validation, Testing

## Practice Exercises
1. Add a new service request category: `payment-method`.
2. Add server-side validation for valid email format.
3. Add a UI badge for high-priority requests.
4. Add an API test for `/api/health`.
5. Add a React component test for the dashboard summary card.
6. Introduce one controlled error and trace it through browser -> API -> logs.
7. Verify authorization by calling a protected route without a token.

## Definition of Done
- API compiles
- Client builds
- Core CRUD works
- Validation errors are visible to users
- Tests pass
