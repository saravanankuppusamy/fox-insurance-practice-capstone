# Day 2 - React + TypeScript Client

## Goals
Build the mental model:
`Component -> Event -> API Service -> Express API -> State Update -> Re-render`.

## Tasks
1. Start the React Vite application.
2. Review `types.ts`, `api.ts`, and `AuthContext.tsx`.
3. Log in with a seed account.
4. Observe ProtectedRoute behavior.
5. Review Dashboard data loading with `useEffect`.
6. Review customers, policies, and requests pages.
7. Create a new service request.
8. Change status and add notes.
9. Use browser DevTools Network tab to trace requests.
