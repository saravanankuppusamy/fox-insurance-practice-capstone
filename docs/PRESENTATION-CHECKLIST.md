# 8-10 Minute Practice Presentation Checklist

1. Business problem and users - 1 minute
2. Architecture overview - 1 minute
3. Login/authentication demo - 1 minute
4. Customer/policy/service-request workflow - 2 minutes
5. Dashboard and filtering - 1 minute
6. Docker / HTTPS explanation - 1 minute
7. Kubernetes resources - 1 minute
8. Challenges, AI usage, lessons learned - 1-2 minutes

Be prepared to explain one backend route, one Mongoose model, one React component, one Dockerfile stage, and one Kubernetes manifest.
